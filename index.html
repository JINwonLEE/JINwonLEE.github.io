소개

약 8년 동안 Agent App, 클라우드 플랫폼, 사용자 대상 서비스를 프로덕션까지 전달해 왔습니다. 지금은 삼성전자에서 AWS EKS 기반 사내 AX Agent Platform을 설계·구축하고 있고, Azure 기반 B2C 생성형 AI 서비스의 한국·UK 출시와 초기 안정화를 지원했습니다.

그 전에는 Samsung Research에서 30,000명의 임직원이 사용하는 전사 AI 챗봇의 프로덕션 전달과 애플리케이션 신뢰성을 리딩했습니다. 삼성전자 네트워크사업부에서는 Kubernetes 플랫폼과 초당 최대 130,000개 패킷을 처리하는 Linux 패킷 미러링 애플리케이션을 만들었고, TmaxOS에서는 OS 수준 AI 어시스턴트를 개발했습니다.

출발점은 연구였습니다. UNIST 석사 과정에서 분산 CNN 학습을 연구해 최대 2.3배의 학습 속도 향상을 보고했습니다. 업무 밖에서는 추천마다 CV 근거를 함께 보여주는 채용 추천 서비스 오퍼나우를 만들고 있습니다.
